How I work

A sample rubric evaluation

This is how I turn an image request into yes/no rubric questions, answer each one with evidence from the output image, and sum up the result. The example was written for this portfolio and contains no client data.

Task type: image editing · user photo · rubric fulfillmentIllustrative example
Input

The user's own photo of a living room with a red armchair next to a window, taken in daylight.

Request
Add a golden retriever puppy sleeping on the red armchair and make the lighting look like sunset. Keep everything else the same.
Evaluator note

4 of 5 criteria met. The puppy was added as requested, asleep on the red armchair, and the rest of the original photo was preserved. R4 fails: the lighting was not changed, so the scene still shows cool daylight with no warm, low sun.

  1. R1Was a golden retriever puppy added to the image?Yes. A golden retriever puppy now appears, with the breed's golden coat and puppy proportions.YES
  2. R2Is the puppy sleeping?Yes. Its eyes are closed and it lies curled up, so the puppy is asleep as requested.YES
  3. R3Is the puppy on the red armchair?Yes. It lies on the seat of the existing red armchair, not on the floor or a new chair.YES
  4. R4Does the lighting look like sunset?No. The room keeps its original cool daylight, with no warm or low-angle light as requested.NO
  5. R5Is the rest of the original photo unchanged?Yes. Furniture, walls, window and framing match the input; only the requested edit was made.YES
Criteria met 4 / 5Visual artifacts: none found
